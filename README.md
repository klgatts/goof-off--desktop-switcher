# 桌面切换工具（Desktop Switcher）v1.2

一个藏在托盘里的小工具：**单击快捷键在工作/摸鱼虚拟桌面之间来回切换，双击回到工作桌面并把默认浏览器切到第一个标签页，长按可以把窗口瞬间藏起来**。免安装、无额外依赖。

程序基于 AutoHotkey v2 开发

## 功能

- **单击快捷键**：在 工作桌面 和 摸鱼桌面 之间来回切换（另一个桌面不存在会自动新建）
- **双击快捷键**：切回 工作桌面，再把默认浏览器（Chrome / Edge / Firefox 等）切到第一个标签页
- **长按 350ms**：完全隐藏当前窗口（从屏幕和任务栏一起消失，真的看不见），再长按一次放出来；恢复时保持藏之前的样子（最大化的还是最大化）
- **智能静音**：离开摸鱼桌面时，若摸鱼焦点在放音视频会自动禁音，回摸鱼自动恢复（可在托盘关闭此功能）
- **托盘右键菜单**：修改快捷键、执行速度延迟、设定工作桌面、离开摸鱼自动静音、开关开机自启、更多（释放所有隐藏窗口 / 使用说明）、退出
- **快捷键设置很人性化**：显示为 `LCtrl+Num*` 这样看得懂的形式，自动区分左右修饰键
- **DLL 已内嵌**：不需要额外放任何 DLL 文件，运行时会自动释放使用

## 使用

### 运行

- **exe 版**：双击 `桌面切换工具v1.2.exe`

运行后任务栏右下角会出现托盘图标，程序常驻后台。

### 快捷键（默认）

| 操作 | 效果 |
|---|---|
| 单击 `LCtrl+Num*` | 在 工作桌面 ⇄ 摸鱼桌面 之间切换 |
| 双击 `LCtrl+Num*` | 切回 工作桌面，并把默认浏览器切到第一个标签页 |
| 长按 `LCtrl+Num*`（350ms） | 隐藏当前窗口；再长按一次放出来（静默，无提示） |

### 工作桌面 / 摸鱼桌面

- 托盘右键 →「设定工作桌面」→ 选「桌面1 是工作桌面」或「桌面2 是工作桌面」，另一个自动就是摸鱼桌面
- 设定会记住，重启后依然有效
- 单击/双击都以工作桌面为基准：离开摸鱼 = 去工作，离开工作 = 去摸鱼

### 智能静音

- 离开摸鱼去工作时，若摸鱼焦点在放音视频（浏览器/播放器/音乐客户端）→ 自动禁音，回摸鱼自动恢复
- 双击时焦点在放音视频 → 顺手静音；长按隐藏的窗口在放音视频 → 静音，放出来 → 恢复
- 不想要自动静音：托盘右键 →「离开摸鱼自动静音」取消勾选

### 修改快捷键

右键托盘图标 → 点「修改快捷键」→ 按下新的组合键即可，改动会记住，下次启动仍然有效。

支持：

- 键盘键 + 修饰键，**区分左右**（`LCtrl` / `RCtrl` / `LAlt` / `RAlt` / `LShift` / `RShift` / `LWin` / `RWin`），Win 键保持独立
- 鼠标**中键**（`MButton`）、**侧键**（`XButton1` / `XButton2`）
- 触发方式：按住修饰键不放连按主键、或修饰键和主键一起按下都可以
- 不支持滚轮键；录制时按 `Esc` 取消

### 执行速度延迟

右键托盘图标 → 点「执行速度延迟」→ 填一个数字（150~1000 毫秒），点确定立即生效并记住。

这是"单击/双击"的判定时间：调大双击更好按（但单击响应稍慢），调小单击更跟手。填 1 会自动变成 150。

## 托盘菜单

| 菜单项 | 作用 |
|---|---|
| 修改快捷键（当前值） | 录制新的快捷键 |
| 执行速度延迟（当前值） | 调整单击/双击判定时间（150~1000 毫秒） |
| 设定工作桌面（当前值） | 选 桌面1/桌面2 为工作桌面，另一个是摸鱼桌面 |
| 离开摸鱼自动静音 | 开关离开摸鱼时的自动禁音（默认开） |
| 开机启动 | 开关登录时自动运行（状态会记住） |
| 更多 → 释放所有隐藏窗口 | 兜底：异常时一键恢复所有没放出来的窗口 |
| 更多 → 使用说明 | 弹出简明操作说明 |
| 退出 | 退出程序 |

## 常见问题

**Q：任务管理器打开时，快捷键没反应？**
这是 Windows 的安全机制（UIPI）：任务管理器是管理员权限窗口，非管理员进程读不到它的键盘输入，任何工具（PowerToys 等）都一样。用完后点一下桌面或普通窗口再按快捷键即可。

**Q：Edge 隐藏后重新唤出，双击和 Ctrl+1 没反应？**
已知的浏览器（Chromium 内核）兼容问题：Edge 被完全隐藏再唤出后，键盘输入会暂时失灵（手动 Ctrl+1 也没用），**用鼠标点一下 Edge 页面任意位置就恢复**。记事本等普通窗口没有这个问题。暂时没有自动修复方案，后续版本再看。

**Q：需要放 DLL 文件吗？**
不需要。VirtualDesktopAccessor.dll 已以 base64 形式内嵌进脚本/exe，运行时自动释放到临时目录并加载。

**Q：默认浏览器怎么识别？**
通过注册表查询系统默认浏览器（http 关联），识别失败时回退到 Microsoft Edge。

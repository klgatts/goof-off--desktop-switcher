# goof-off--desktop-switcher
Windows 虚拟桌面摸鱼切换小工具：单击一键切桌面，双击回桌面1并切到浏览器第一个标签；支持自定义快捷键、开机自启、免安装 exe。Lightweight Windows virtual-desktop switcher: single press toggles desktops, double press returns to desktop 1 and focuses the first tab of your default browser. Custom hotkey, auto-start, standalone exe.
